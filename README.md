# 🌆 CitySense — Traffic & Pollution Analyzer

> Breathe smarter. Move better. Live greener.

CitySense is an AI-powered chatbot built for the **Tradition Hacks Hackathon** under the domain **AI for Sustainable Smart City Solutions**.

## 🚀 Live Demo
[citysense.streamlit.app](https://citysense.streamlit.app)

## 💡 What it does
CitySense analyzes real-time traffic and pollution data across Kolkata zones and provides:
- 🌫️ AQI (Air Quality Index) for specific zones
- 🚗 Traffic congestion updates
- 🌿 Safest zone recommendations
- 🏥 Health tips based on pollution levels
- 📊 Full city pollution overview

## 🛠️ Tech Stack
- Python
- Streamlit
- AI/ML logic for pollution analysis

## 📦 Run Locally

```bash
git clone https://github.com/yourusername/traditionhacks.git
cd traditionhacks
pip install -r requirements.txt
streamlit run app.py
```
